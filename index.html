Where the code is now
  • snake.model holds the game rules with no Swing code: GameState, Snake, Point, Direction, BoosterEffect.
  • snake.ui has MenuFrame, GameFrame, BoardPanel and GameController (timer, pause, game over).
  • snake.persistence saves games and settings as JSON with Gson; snake.audio plays the MP3s.
  • Keys: W/A/S/D or arrows move, SPACE starts, P pauses, M mutes music, N mutes effects, ESC returns to the menu.
  • Saves are JSON files in saves/; settings and the high score are kept in settings.json. Missing or corrupted files show an error.
  • JUnit 5 tests cover the game rules and saving, using @TempDir for temporary files.
  • The board builder was dropped from the scope. The Git branching workflow is still to do.
